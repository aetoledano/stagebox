# Sound, Wi-Fi and tools

[Documentation](../README.md) · [StageBox](../../README.md)

Open the gear-shaped **Tools** button in the top bar to reach everyday settings.
The library's game cards remain inactive while a settings dialog is open.

## Sound

Open **Sound Settings** to select a Windows output device, change master volume
or mute. The active device is marked in the list. While browsing StageBox,
right-stick up/down adjusts volume and shows a short volume overlay. That stick
shortcut is disabled during games. Keyboard media volume/mute keys still work
without bringing the launcher to the foreground.

## Wi-Fi

Open **Wi-Fi Networks**, refresh the list and select a network. Saved secure
networks can reconnect without asking for a password; a new secured network
asks for one. Windows Wi-Fi hardware, drivers and services must be available.
For kiosk setup problems, see [troubleshooting](../troubleshooting.md).

## Bluetooth and controllers

Use **Bluetooth Devices** to pair or forget Windows devices. Use **Controllers**
to view connected/saved pads, choose their input mode, record a mapping or test
buttons and rumble. The top bar shows connected-controller count and connection
status. See [Bluetooth](bluetooth.md) and [Controllers](controllers.md).

## Library and power controls

**Reload Games** refreshes the game list after installs or metadata changes.
**Open Games Folder** opens the configured local-game root. Restart, power-off
and exit controls are also in the tools menu. Exit behavior depends on regular
app/debug mode versus kiosk mode; see [configuration](../configuration.md).
