# Your first session

[Documentation](README.md) · [StageBox](../README.md)

Once StageBox is running on Windows, connect a controller and pick a game. [Installed Steam games](features/steam.md) appear automatically; [other local games](game-library.md) need a small launch file.

1. Open StageBox and let your library load.
2. Browse with the D-pad or left stick, or use keyboard arrows.
3. Tap **A** or press **Enter** to start a game. StageBox shows its launch screen
   and moves out of the way while you play.
4. Exit the game to return to your library. When using RetroBat, quit RetroBat
   itself to return to StageBox.
5. Use the topbar **Steam** or **RetroBat** button to open that frontend. If it
   is missing, StageBox offers its installer; complete setup before opening it.
6. Open the **Tools** gear for controller settings, Bluetooth, Wi-Fi, sound,
   reloading games and power options. See [Settings](features/settings.md).

Steam keeps its own sign-in, update and first-run screens. Some setup prompts
need a keyboard or mouse; see the [Steam guide](features/steam.md).

## Everyday controls

| Action | Controller / keyboard |
| --- | --- |
| Browse games | D-pad / left stick, or arrow keys |
| Launch a selected game | Tap A, or Enter |
| Local-game input options | Hold A for one second, or Context Menu / Shift+F10 |
| Back or dismiss | B, or Escape where supported |
| Volume while browsing | Right stick up/down |
| Stop a tracked local/Steam game | Hold Start+Back; RetroBat uses its own exit controls |

Library cards use controller/keyboard activation; mouse clicks do not launch them. Mouse controls remain available for settings. Some Windows setup/elevation dialogs still need a keyboard or mouse.

If a game does not show up, see [troubleshooting](troubleshooting.md).
