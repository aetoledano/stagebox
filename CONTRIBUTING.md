# Contributing to StageBox

Ideas, reproducible bug reports and focused pull requests are welcome.

- Read the [development guide](docs/development.md) for required Linux tools,
  the Wails build flow, commands and Windows validation.
- Read [CODEX.md](CODEX.md) for architecture, data flow and implementation traps.
- Explain the problem, resulting behavior and checks performed in your pull
  request. List relevant tests and hardware checks for the maintainer to run;
  do not claim checks that were not performed.
- Keep user guides current and add architecture/build changes to CODEX.

Use the issue templates and include your StageBox/Windows version, reproduction
steps and controller model/connection when relevant. Redact local paths,
network names, credentials and device identifiers from logs. For sensitive
reports, follow [SECURITY.md](SECURITY.md).

Contributions to StageBox's original code use GPL-3.0-only. Third-party
components retain their own [licenses](THIRD_PARTY_NOTICES.md).
